# C Companion 1.10.0 — Welcome สีมิ้นต์

ปรับหน้าแนะนำจากโทนมืดเป็นขาว–เขียวอ่อนให้เข้ากับห้องแชท ใช้หัวเรื่องภาษาไทยอธิบายสิ่งที่บอทช่วยได้ และคงมังกรกับหนังสือ3Dที่ผู้ใช้ชอบ

- จัดองค์ประกอบใหม่ด้วยเส้นวงโคจร กริดบาง แผ่นกระจกสว่าง และพื้นที่ว่างที่อ่านง่าย
- เปลี่ยนแกลเลอรีที่ตรึงหน้าจอเป็นการเลื่อนแนวนอนเฉพาะการ์ด พร้อมปุ่มเลือกสามโหมด ปุ่มก่อนหน้า/ถัดไป และสถานะ ไม่บังคับเปลี่ยนการเลื่อนหน้าแนวตั้งเป็นแนวนอน
- ปุ่มดูตัวอย่างเลือกโหมดให้ตรงกับการ์ดที่กด
- เพิ่มประโยชน์หลักสามด้าน และเส้นทางคำตอบสี่ขั้นแบบกดดูคำอธิบายได้
- ปรับข้อความอธิบายแหล่งข้อมูลให้ตรงระบบ กดชื่อบททั้ง12บทเพื่อเปิดหน้าPDFได้
- เพิ่มแถบแสดงระยะการอ่าน การตอบสนองเมื่อชี้การ์ด และคงกล้อง3D/หนังสือหมุนตามการเลื่อน ใช้การเลื่อนปกติของเบราว์เซอร์ และเริ่ม3Dเฉพาะเมื่อมังกรอยู่ในจอ
- รองรับ320px, reduced motion, Save-Data, WebGL fallback และเนื้อหาหลักเมื่อปิดJavaScript ไม่เพิ่มdependencyหรือวิดีโอ

ทางเข้ายังคง / → /welcome/ → /chat/ ชื่อแท็บและไอคอนตรงกัน ไม่เปลี่ยนข้อมูล ประวัติ นโยบายคำตอบ หรือผลวิจัย คู่มือรุ่น1.9.0ยังอธิบายขั้นตอนติดตั้งและใช้ห้องแชทได้ หน้าตาของWelcomeเปลี่ยนตามบันทึกนี้

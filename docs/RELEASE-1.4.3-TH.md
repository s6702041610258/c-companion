# C Companion 1.4.3 — ตอบให้ตรงคำถามเรื่องบทและหน้า

## ปัญหาที่แก้

รุ่น 1.4.2 ตรวจข้อความในอัญประกาศก่อนตีความเจตนา เมื่อพบ “if else” ในหนังสือจึงตอบหน้า 32, 35 และ 36 ทันที ทั้งที่ผู้เรียนอาจถามว่าอยู่บทไหน หรือขอให้อธิบายความหมาย ทดสอบทำซ้ำพบปัญหาทั้งสองกรณี

## พฤติกรรมใหม่

- ตีความคำถามปัจจุบันและประวัติล่าสุดก่อนเลือกเส้นทางค้นตำแหน่งหนังสือ ใช้ Hermes รอบตีความที่มีอยู่ ไม่เปลี่ยนโมเดลหรือฝึกโมเดลใหม่
- แยกคำถามหาบท หาหน้า และอธิบายเนื้อหา คำถามผสมขออธิบายยังเข้าสู่เส้นทางคำตอบที่ตรวจอ้างอิง
- “if else อยู่บทไหน” ตอบบทที่ 4 เรื่อง ตัดสินใจด้วยเงื่อนไข พร้อมช่วงหน้าหนังสือ 32–42 และหลักฐานจากหนังสือ
- “if else อยู่หน้าไหน” แสดงหน้าที่พบข้อความจริง พร้อมเลขหน้า PDF และข้อความอ้างอิง
- “ช่วยอธิบาย ‘if else’” ไม่ถูกดักให้ตอบรายการเลขหน้าอีกต่อไป
- “แล้วอยู่บทไหน” ให้ตัวตีความใช้หัวข้อจากแชทปัจจุบัน ถ้าไม่ทราบหัวข้อให้ถามกลับ
- คำถามหาบทค้นทั้งเล่ม แม้ผู้ใช้เลือกบทอื่นไว้ โดยคงการเลือกบทเดิม
- ถามตำแหน่งหนังสือในโหมดฝึกโจทย์ได้ โดยไม่ถือเป็นการลองตอบหรือปลดล็อกเฉลย
- ถ้า AI ไม่พร้อม ยังมีการค้นหน้าตรงข้อความและค้นบทจากหัวข้อที่รู้จักเป็นทางสำรอง เครื่องหมายอัญประกาศเพียงอย่างเดียวไม่บังคับเส้นทางนี้
- อัปเลขรุ่นที่หน้าเว็บ package/lockfile Docker และ Compose เป็น 1.4.3

## การตรวจสอบ

เพิ่ม regression ที่พบว่าล้มเหลวในรุ่นเดิม แล้วตรวจหน่วยค้นหนังสือ ตัวตีความคำถาม HTTP และเบราว์เซอร์ รวมทั้งการเก็บข้อความต้นฉบับ อ้างอิง และการคงค่าบทที่เลือก ตรวจชุดทดสอบเดิม การค้นหนังสือ TypeScript และ build ด้วย ผลตรวจปล่อยรุ่นและสถานะ production ต้องยืนยันจาก commit/image ที่ติดตั้งจริง

## ข้อจำกัดและย้อนรุ่น

การตีความของ AI อาจผิดได้ โดยเฉพาะคำถามกำกวม ชื่อหัวข้อที่ไม่รู้จักอาจต้องขอข้อความเพิ่ม การตรวจผ่านไม่รับประกันทุกสำนวน คำถามหาหน้าใช้การค้นข้อความตรง ไม่ใช่การพิสูจน์ว่าคำตอบหรือข้ออ้างในข้อความนั้นถูกต้อง

ไม่มีการเปลี่ยนฐานข้อมูล หนังสือ dependencies บัญชีหรือค่าตั้ง AI การย้อนรุ่นใช้ image/config 1.4.2 และ volume เดิม ห้ามลบ volume ของผู้เรียน

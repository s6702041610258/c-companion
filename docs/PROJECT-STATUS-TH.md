# สถานะ C Companion

## รุ่น 1.6.0 — ห้องเรียนกระจกฝ้า

ปรับสัดส่วนพื้นที่เรียนรู้ แถบเมนู และช่องพิมพ์ให้สมดุล ใช้กระจกฝ้าโทนเขียว–ฟ้า เงาบาง ภาพบอทและไอคอนประกอบ หน้าอ่านคำตอบยังมีพื้นหลังชัดเจน รองรับธีมสว่าง/มืด จอแคบ ลิงก์ข้ามเมนูสำหรับคีย์บอร์ด และการลดภาพเคลื่อนไหว ปรับเลขรุ่นและคู่มือพร้อมกัน ไม่มีการเปลี่ยน backend/schema/dependencies หลักฐานการเผยแพร่อยู่ใน Release 1.6.0

## รุ่น 1.5.0 — โปรไฟล์เพื่อนติวและหน้าคุยที่เป็นระเบียบ

เพิ่มภาพ SVG หุ่นยนต์อ่านหนังสือที่ออกแบบสำหรับ C Companion ใช้ร่วมกันในโลโก้ หน้าเริ่มต้น แถบหัวเว็บ คำตอบและสถานะกำลังตอบ จัดกล่องคำตอบ แถบโหมด ช่องพิมพ์ และประวัติที่เลือกให้ชัดขึ้น รองรับมือถือและสองธีม โดยคงข้อความผู้ใช้ด้านขวาและไม่มีชื่อผู้ส่งซ้ำ ไม่มีการเปลี่ยนbackend/schema/dependencies

## รุ่น 1.4.4 — แยกฝั่งข้อความในแชท

ข้อความผู้ใช้อยู่ขวาพร้อมกล่องสีและชื่อผู้ส่ง คำตอบบอทอยู่ซ้าย ปรับความกว้างบนมือถือและสีทั้งสองธีม คงพื้นที่อ่านโค้ดและอ้างอิง ตรวจหน้าจอจริงขนาด1366/390pxทั้งlight/darkและbrowser33กรณีผ่าน ไม่มีการแก้backendหรือschema

## รุ่น 1.4.3 — แยกคำถามหาบท หาหน้า และอธิบาย

ตีความเจตนาก่อนค้นข้อความในหนังสือ ตอบบทที่ถามพร้อมหลักฐาน และคงบริบทแชท/สถานะโจทย์ รายละเอียดและข้อจำกัดดู [บันทึกรุ่น 1.4.3](RELEASE-1.4.3-TH.md) สถานะ deploy ต้องตรวจจาก runtime จริง

## รุ่น 1.4.2 — ค้น Flowchart และตารางสัญลักษณ์ครบ

- คำถาม Flowchart / flow chart / flow-chart / ผังงาน / โฟลว์ชาร์ต ดึงนิยามหน้า 5 และตารางสัญลักษณ์หน้า 6–7 ก่อนคำค้นทั่วไปที่ AI เพิ่มมา
- ไม่ให้คะแนนหน้าเพียงเพราะอยู่ในบทที่เลือก เมื่อระบุหัวข้อที่มีหน้าหลักชัดเจนแต่เลือกบทอื่นไว้ จะค้นข้ามบทและแจ้งบทที่ใช้ในคำตอบ โดยไม่เปลี่ยนค่าบทที่ผู้ใช้เลือก
- ในโหมดติวและโจทย์ ให้หลักฐานของคำถามปัจจุบันมาก่อนหน้าที่ใช้ในคำตอบก่อนหน้า
- แยก “หลักฐานที่ค้นครั้งนี้ไม่พอ” จาก “นอกขอบเขตภาษา C”; ห้ามสรุปว่าไม่มีเนื้อหาในหนังสือทั้งเล่มจากหน้าที่แนบเพียงบางส่วน
- ไม่เปลี่ยนฐานข้อมูล โมเดล dependencies หรือหนังสือต้นฉบับ ย้อนด้วย image/config ก่อนหน้าและข้อมูล volume เดิมได้
- ชุดทดสอบเพิ่มครอบคลุมหน้าตารางที่ต่อกัน คำค้นที่ขยายกว้าง บทที่เลือกไม่ตรง และ HTTP ที่รักษาข้อความเดิม/อ้างอิง/ค่าบทเดิม
- สถานะ CI และหลักฐาน deploy ให้ตรวจ GitHub release v1.4.2; ข้อความนี้อธิบายพฤติกรรมซอร์ส ไม่ยืนยันว่าสภาพ runtime ปัจจุบันตรงรุ่น

- เปลี่ยนภาษาด้วยคำสั่งในแชท เช่น “ตอบเป็นอังกฤษ” หรือ “ตอบเป็นไทย” โดยเก็บประวัติและสถานะโจทย์

- พิมพ์ขอเปลี่ยนภาษาต่อเนื่องหรือเฉพาะครั้งได้ ครอบคลุมทุกโหมด สรุป คู่มือ คุยเล่นและข้อความสำรอง ไม่เพิ่มรอบ AI เพื่อแปลทุกคำตอบ
- เพิ่มตาราง chat_preferences และ job_languages แบบแยก ไม่เปลี่ยนคอลัมน์ตารางเดิม แชทเก่าใช้ไทย; ตรวจเจ้าของ ปฏิเสธเปลี่ยนค่าระหว่างงานค้าง และบันทึกการเปลี่ยนผ่านข้อความพร้อมคำตอบ
- ขอแปลโจทย์เดิมได้โดยไม่ถือว่าลองตอบและไม่ปลดล็อกเฉลย

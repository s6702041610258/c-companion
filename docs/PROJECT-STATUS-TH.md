# สถานะ C Companion

อัปเดต 28 กันยายน 2026 — ซอร์สรุ่น 1.2.1; สถานะ CI และการ deploy จริงบันทึกใน GitHub release ของรุ่นนี้

## งานรอบ 1.2.1

- **DONE** คำปฏิเสธ/ข้อความยกตัวอย่างไม่เรียกสรุปจากกฎลัด และมี veto เมื่อโมเดลจัดคำปฏิเสธผิด
- **DONE** การยกเลิกตั้งแต่สร้างแชทและช่วงรับเลขงาน พร้อมคืน draft และไม่ปล่อยงานที่รู้เลขไว้เบื้องหลัง
- **DONE** สถานะลองตอบโจทย์ใน SQLite พร้อม reset เมื่อขอข้อใหม่และบริบทโจทย์แยกจากหน้าต่างประวัติล่าสุด
- **DONE** เก็บหลักฐานตรงคำถามอาร์เรย์ก่อนเพิ่ม prerequisite จาก planner
- **RELEASE GATE** ตรวจ CI, source manifest, สำรอง/กู้คืน และ browser smoke จริงก่อนเผยแพร่

## งานรอบ 1.2.0

- **DONE** ทำซ้ำปัญหา: ประโยคเริ่มเรียนที่ลงท้ายด้วยอัญประกาศ/ตัวอักษรเกินตกไปเส้นทางไม่พบเนื้อหา
- **DONE** รองรับอัญประกาศในข้อความสนทนา และเพิ่ม Hermes ช่วยแยกเจตนา/ขยายคำค้นจากประวัติเฉพาะแชท
- **DONE** ถามกลับเมื่อกำกวม ตรวจรูปแบบคำตอบตัวตีความ จำกัดเวลาและขนาดข้อมูล รักษาการยกเลิก/สิทธิ์เจ้าของ/ข้อความต้นฉบับ/การตรวจอ้างอิง
- **DONE** แยกคำค้นโครงสร้างโปรแกรมออกจาก struct
- **RELEASE GATE** ต้องตรวจ CI, สำรองและทดลองกู้บนสำเนา, สร้าง release ตรง commit, สลับ app/backup/monitor และทดสอบผู้ใช้จริงก่อนประกาศ deploy สำเร็จ

## เกณฑ์ปล่อยรุ่น

ตัวอย่างผู้ใช้ทั้งสองต้องเริ่มเรียนได้; คำทักทายพร้อมคำถาม C ยังได้อ้างอิง; คำถามต่อเนื่องใช้หัวข้อเดิม; ข้อความกำกวมถามกลับ; คำปฏิเสธ/ภาษาอื่นไม่ถูกตีความเป็นเริ่มเรียน C; ข้อความต้นฉบับไม่เปลี่ยน; การยกเลิกและการแยกแชทผ่าน

## ข้อจำกัดและการย้อนรุ่น

การตีความเป็นการตัดสินใจของโมเดล อาจผิดได้แม้ชุดทดสอบผ่าน เพิ่ม AI หนึ่งรอบสำหรับข้อความที่ไม่เข้าเส้นทางตรง ไม่ได้เปลี่ยนโมเดลหรือฝึกน้ำหนัก Hermes ใหม่ รุ่น 1.2.1 เพิ่ม quiz_state แบบ additive โดยไม่เปลี่ยนตารางเดิม/dependency/สิทธิ์เครื่องมือ ย้อนกลับด้วย source/image/config ของ 1.2.0 และ volume เดิมหาก HTTPS, สุขภาพ หรือการถามตอบจริงไม่ผ่าน

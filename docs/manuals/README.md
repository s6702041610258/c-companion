# คู่มือ C Companion 1.15.0

ปรับปรุง 13 ตุลาคม 2569 คู่มือใช้มาสคอตยีราฟเสื้อแดงและอธิบายทางเข้าหน้าแนะนำกับห้องสนทนาของรุ่นปัจจุบัน

- [คู่มือติดตั้งและใช้งานฉบับเต็ม 12 หน้า](../../คู่มือการใช้งานและติดตั้งแชทบอท.pdf)
- [คู่มือภาพฉบับย่อ 4 หน้า](C-Companion-Visual-Guide-TH.pdf)
- [HTML ฉบับเต็ม](C-Companion-User-Guide-TH.html)
- [HTML ฉบับย่อ](C-Companion-Visual-Guide-TH.html)

เริ่มจากฉบับเต็มเมื่อติดตั้งครั้งแรก ใช้ฉบับย่อทบทวนขั้นตอน ทั้งสองฉบับรองรับ Windows, macOS และ Linux ผู้ติดตั้งใช้บัญชีบริการ AI ของตนเอง

HTML ฝังฟอนต์และมาสคอต เปิดออฟไลน์ได้ เมื่อดาวน์โหลดไฟล์แล้วให้เปิดด้วยเบราว์เซอร์ หากพิมพ์ PDF ให้ใช้กระดาษ A4 เปิดกราฟิกพื้นหลังและปิดหัว/ท้ายหน้าของเบราว์เซอร์

สำหรับผู้ดูแลเอกสาร: รัน `node ops/render-manuals.mjs` จากรากโปรเจกต์เพื่อสร้าง PDF ทั้งสองฉบับและภาพสรุปสำหรับ README โดยต้องติดตั้ง dependencies และ Chromium ของ Playwright แล้ว

หนังสือเรียน C Companion เป็นผลงานของผู้ช่วยศาสตราจารย์ ดร. สรเดช ครุฑจ้อน (Soradech Krootjohn) และมีสิทธิ์แยกตาม `book/NOTICE.md` เลขรุ่นคู่มือหมายถึงรุ่นแอป ไม่ใช่รุ่นหนังสือเรียน

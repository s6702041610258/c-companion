# C Companion 1.8.0

รุ่นนี้ปรับการอ่านและใช้งานห้องแชท โดยคงมังกรเขียว ธีมกระจกฝ้า สองธีม และรูปแบบผู้ใช้ขวา/บอทซ้าย

- ช่องพิมพ์เริ่มกะทัดรัดและขยายตามข้อความไม่เกิน160พิกเซล รองรับข้อความโค้ดหลายบรรทัด
- กล่องโค้ด C แยกสีคำสั่ง สตริง ตัวเลข และคอมเมนต์ แสดงภาษา คัดลอกข้อความต้นฉบับ และขยายโค้ดยาวได้; ไม่รันโค้ด
- เลื่อนอ่านย้อนหลังได้โดยคำตอบใหม่ไม่ดึงลงล่างหรือเปิดแผงอ้างอิงแทรก มีปุ่มกลับไปข้อความล่าสุด
- เปลี่ยนโหมดขณะมีบทสนทนาหรือข้อความร่างต้องยืนยันก่อน แชทเดิมยังอยู่และข้อความร่างย้ายตามไป การกดโหมดเดิมไม่ล้างแชท
- ย่อเมนูบนคอมพิวเตอร์ ค้นหาประวัติจากชื่อ จัดกลุ่มตามวัน และโหลดรายการเก่าเพิ่มทีละ30รายการ โดยตรวจเจ้าของทุกคำขอ
- ปุ่มอ้างอิงระบุทั้งบทและหน้า ปรับตัวหนังสือและปุ่มบนมือถือให้ไม่เบียดกัน
- “การใช้งานและคู่มือ” มี PDF ในแอปและผลตรวจเข้าถึงบริการ AI ใช้เวลาไม่เกิน5วินาทีและเก็บผลไม่เกิน30วินาที ไม่เปิดเผยข้อมูลเชื่อมต่อหรือกุญแจ ไม่สร้างคำตอบเพื่อทดสอบ
- คู่มือฉบับเต็ม12หน้าและคู่มือภาพ4หน้าอัปเดตเป็นรุ่น1.8.0

## การตรวจสอบ

ทดสอบหน่วย131กรณี ชุดค้นคืน24กรณี และเบราว์เซอร์42กรณี รวมความเป็นเจ้าของประวัติ การเปลี่ยนโหมด การคัดลอกโค้ด การเลื่อนอ่านย้อนหลังและมือถือ ตรวจ TypeScript/build พร้อมตรวจภาพจริงที่320/390/1366พิกเซลในสองธีม ผลเบราว์เซอร์ใช้บริการจำลองสำหรับความแน่นอนของพฤติกรรม ไม่ใช่ผลวัดความถูกต้องของ AI

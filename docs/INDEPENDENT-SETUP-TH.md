# เริ่มใช้ C Companion บนเครื่องตัวเอง

คู่มือสำหรับรุ่น **1.5.0** ปรับปรุง 8 ตุลาคม 2569 · [คู่มือ PDF](../คู่มือการใช้งานและติดตั้งแชทบอท.pdf)

ผู้รับต้องมี Docker Desktop หรือ Docker Engine + Compose และบัญชี AI ของตัวเอง **ไม่ต้องติดตั้ง Hermes แยก** ตัวเริ่มระบบจะดาวน์โหลด Hermes image ทางการและรันใน Docker คู่กับเว็บ โดยไม่ใช้ Hermes, กุญแจ หรือ VPS ของผู้สร้าง

## เริ่มครั้งแรก

- macOS: เปิด `Start.command` หรือรัน `bash start.sh`
- Windows: เปิด `Start.bat`
- Linux: รัน `bash start.sh`

Hermes จะเปิดตัวเลือกผู้ให้บริการ AI ให้เข้าสู่ระบบหรือกรอก API key แล้วเลือกโมเดล ใช้บัญชีของผู้ติดตั้งเองเท่านั้น OAuth และรูปแบบกุญแจต่างกันตามผู้ให้บริการ ดู [รายชื่อผู้ให้บริการทางการ](https://hermes-agent.nousresearch.com/docs/integrations/providers) เมื่อเลือกเสร็จ ระบบจะปิดเครื่องมือเอเจนต์ที่ไม่จำเป็น เริ่ม Hermes กับเว็บ ทดสอบการตอบจริงหนึ่งครั้ง และเปิด `http://localhost:8091`

หากเลือกผิดหรือเปลี่ยนโมเดลภายหลัง ให้รัน `bash start.sh --choose-model` หรือ `Start.bat -ChooseModel` ระบบเก็บประวัติสนทนาเดิมไว้ หากอินเทอร์เน็ตขัดข้องหรือบัญชี AI ใช้ไม่ได้ จะบอกข้อผิดพลาดและให้ลองตั้งค่าใหม่ โดยไม่ลบข้อมูล

## ข้อมูลและการเชื่อมต่อ

หน้าเว็บเปิดเฉพาะ `localhost` Hermes API อยู่ใน Docker network ภายใน ไม่เปิดพอร์ตออกเครื่อง กุญแจระหว่างเว็บกับ Hermes สุ่มใหม่ต่อการติดตั้งและอยู่ใน `.env` ของผู้ติดตั้ง ข้อมูลแชต สำเนาฐานข้อมูล บัญชี AI และโมเดลอยู่ใน Docker volumes ของเครื่องผู้ติดตั้ง ไม่ส่งข้อมูลให้ผู้สร้าง

ผู้ให้บริการ AI ที่เลือกจะได้รับคำถามและข้อความหนังสือบางส่วนเพื่อสร้างคำตอบ การใช้งาน cloud AI ต้องมีอินเทอร์เน็ตและอาจมีค่าใช้จ่ายตามบัญชีนั้น เครื่องที่ไม่มี Docker ต้องติดตั้ง Docker ก่อน ตัวเริ่มระบบไม่ติดตั้ง Docker Desktop ให้เอง

## เปลี่ยนหนังสือ

ชุดนี้ตั้งบทเรียนและเลขหน้าอ้างอิงตามหนังสือภาษา C ที่แนบมา การแทน PDF อย่างเดียวไม่เปลี่ยนเนื้อหาที่บอตค้น ต้องสร้าง `book/index.json` ใหม่ ปรับ `app/curriculum.mjs` และทดสอบคำตอบกับเลขหน้าอีกครั้ง ยังไม่มีปุ่มนำเข้าหนังสือใหม่อัตโนมัติ

# C Companion 1.12.0 — เปิดโลกการเรียนรู้ผ่านหนังสือ

ปรับเฉพาะ Landing Page ให้ชื่อ C COMPANION ขนาดใหญ่เป็นจุดเด่น พร้อมฉากมังกรเขียวและหนังสือสามมิติ เปลี่ยนมุมกล้องและตำแหน่งตัวอักษรตามการเลื่อนหน้า ใช้พื้นเขียวอ่อนและแสงนุ่มให้เข้ากับห้องเรียน

- หน้าเปิดบอกประโยชน์และมีปุ่มเข้าแชททันที ไม่บังคับรอแอนิเมชัน
- จัดตัวอักษรขนาดใหญ่ตามพื้นที่จอ แยกชื่อสองบรรทัดบนมือถือ
- สร้างหนังสือเปิดสามมิติพร้อมหน้ากระดาษและที่คั่นหนังสือ และภาพสำรองเมื่อ WebGL ใช้ไม่ได้หรือผู้ใช้ลดการเคลื่อนไหว
- ใช้โครงเรื่องจากปัญหาผู้เรียน → สามโหมด → ตัวอย่าง → แหล่งอ้างอิง → เว็บ/ติดตั้งเอง → คำถามที่พบบ่อย
- ปรับสี ระยะห่าง และรูปแบบส่วนเนื้อหาให้ต่อเนื่องกัน
- ฉากโหลดตามความจำเป็น วาดเมื่อเกิดการเปลี่ยนแปลง หยุดเมื่อพ้นหน้าจอ/ซ่อนแท็บ จำกัดความละเอียดมือถือ และมีปุ่มปิดการเคลื่อนไหว
- คงตัวอย่างโต้ตอบ 3 โหมด เนื้อหา 12 บท ลิงก์หนังสือ คู่มือ GitHub และทางเข้าห้องแชท

แนวคิดตัวอักษรขนาดใหญ่และความลึกอ้างอิง Kage ของ ThreeUI ตามแนวทางที่ผู้ใช้อนุมัติ งานนี้ปรับจากซอร์ส Landing ของ C Companion โดยสร้างฉากให้เข้ากับการเรียนภาษา C ไม่ได้ฝังหน้า ThreeUI หรือแจกภาพฉากวัด/แพ็กเกจต้นฉบับ

## ขอบเขตและการตรวจ

ไม่มีการแก้ไฟล์ใน `web/` หรือ `app/` หน้าห้องแชทและระบบตอบคำถามคงเดิม หมายเลขรุ่นห้องแชทที่แสดงอยู่ยังเป็นรุ่น UI 1.11.0 ส่วนแพ็กเกจรวมเป็น 1.12.0

ตรวจ unit 131 รายการ, retrieval 24 กรณี, TypeScript, production build และ browser 54 รายการ รวมจอ 320/390/768/1440, CSP, reduced motion, ปิด JavaScript, WebGL ใช้ไม่ได้, demo keyboard และการเข้าแชทเมื่อสคริปต์ฉากไม่โหลด ทั้งนี้ browser tests ใช้ provider จำลองสำหรับส่วนแชท ไม่ใช่การประเมินความแม่นยำ AI

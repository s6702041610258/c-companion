# C Companion 1.14.0 — Mongkoi learning studio

Landing ใหม่ใช้ฉากห้องเรียน 3D เต็มพื้นที่เปิดบนคอมพิวเตอร์ กล้องเคลื่อนต่อเนื่องตามการเลื่อน ตั้งแต่มุมกว้าง ผ่านโต๊ะเรียน จนเข้าใกล้มาสคอต

- ปั้น “มองคอย” ใน Blender: ยีราฟอ้วนคอสั้น เสื้อแดง ปักชื่อไทยและ MONGKOI ด้วยชิ้นงานสามมิติ
- เพิ่มโต๊ะ จอแสดงโค้ด C คีย์บอร์ด โคมไฟ ต้นไม้ ชั้นหนังสือ และแท่นพร้อมแสงเงา
- ใช้โมเดลหนังสือ CC0 ของ John Malcolm / Poly Haven พร้อมเครดิต แทนกระดาษลอย
- แสดงมาสคอตเด่นขึ้น รักษาชื่อ C COMPANION และธีมดำ–แดง–งาช้าง
- พื้นผิวโหลดจากเว็บเดียวกัน ไม่ผ่อนนโยบาย CSP และไม่เรียกบริการภายนอก
- มือถือใช้ฉากย่อและไม่โหลดโมเดลหนังสือ; reduced motion/data saver ใช้ภาพสำรอง
- โหลดโมเดลเมื่อเห็นฉาก วาดเมื่อมีการเปลี่ยนกล้อง หยุดเมื่อซ่อน และคืนหน่วยความจำเมื่อปิด motion
- ปุ่มเข้าแชท คู่มือ ตัวอย่าง และเนื้อหาทั้งหมดยังคงเข้าถึงได้เมื่อ 3D โหลดไม่สำเร็จ

ไม่มีการแก้หน้าห้องแชทหรือระบบตอบคำถามใน web/ และ app/ มาสคอตใหม่ใช้เฉพาะ Landing ตามขอบเขตที่ขอ

ผลตรวจ: unit 131, retrieval 24, TypeScript, production build และ browser 59 รายการ ผ่าน รวมฉากเต็มพื้นที่ โหลดโมเดล/พื้นผิว โมเดลหาย WebGL ใช้ไม่ได้ ปิด JavaScript มือถือ และการเคลื่อนกล้อง ตัวทดสอบแชทใช้บริการจำลอง ไม่ใช่การประเมินความแม่นยำคำตอบใหม่

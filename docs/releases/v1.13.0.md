# C Companion 1.13.0 — Midnight library

ปรับเฉพาะ Landing Page ตามคำขอให้ใกล้บรรยากาศ Kage ของ ThreeUI: พื้นดำอมคราม แสงแดง vermilion ตัวอักษรสีงาช้าง และชื่อ C COMPANION ขนาดใหญ่

- ฉากเดสก์ท็อปต่อเนื่องสามช่วง ใช้การเลื่อนปกติและ CSS sticky: มุมกว้าง → ผ่านหน้ากระดาษ → เข้าใกล้มังกร
- กล้องเดินตามเส้นโค้ง เปลี่ยนระยะ มุมมอง และจุดที่มอง พร้อมข้อความเล่าเรื่องตามจังหวะ
- เพิ่มหน้ากระดาษ 12 แผ่นเป็นฉากหน้า/หลัง พระจันทร์แดง และประกายแสงที่ขยับตามการเลื่อน
- ปรับสีส่วนตัวอย่าง สามโหมด หนังสือ คู่มือ และ FAQ ให้ต่อเนื่องทั้งหน้า
- กดข้ามไปเนื้อหาหรือเปิดแชทได้ระหว่างฉาก ไม่มีการล็อกล้อเลื่อน
- มือถือใช้การเลื่อนปกติและกล้องระยะกว้าง ลดภาระและไม่ตรึงฉากยาว
- รองรับ reduced motion, data saver, ปิด JavaScript และ WebGL ใช้ไม่ได้ พร้อมภาพสำรอง
- โหลดฉากเมื่อเห็นจริง วาดเมื่อกล้องเปลี่ยนเท่านั้น และหยุดวาดเมื่อแท็บซ่อนหรือฉากพ้นจอ

ฉากนี้สร้างต่อจากมังกรและหนังสือของ C Companion โดยอ้างอิงบรรยากาศและหลักการกล้องของ Kage ไม่ได้ฝังเว็บไซต์หรือคัดลอกฉากวัดต้นฉบับ

ไม่มีการแก้ `web/` หรือ `app/` รุ่น UI ห้องแชทยังคงเดิม ส่วนแพ็กเกจรวมเป็น 1.13.0

## ผลตรวจในเครื่องก่อนปล่อยรุ่น

ผ่าน unit 131 รายการ, retrieval 24 กรณี, TypeScript, production build และ browser 56 รายการ รวมการเลื่อนสามฉาก การคืนหน้าเมื่อปิด motion จอ 320/390/768/1440, CSP, WebGL failure และ JavaScript disabled ตรวจภาพจริง desktop/mobile และเส้นทางเข้าแชทแล้ว ทั้งนี้การทดสอบแชทอัตโนมัติใช้ provider จำลอง ไม่ใช่ผลประเมินความแม่นยำ AI

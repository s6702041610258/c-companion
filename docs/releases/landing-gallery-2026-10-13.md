# Landing — บอร์ดผู้จัดทำ (13 ตุลาคม 2569)

คงรุ่นระบบ 1.15.0 ตามคำขอผู้ใช้ ระบุการแก้ไขด้วย Git commit แทนการเพิ่มรุ่น

- แทนชั้นหนังสือด้วยกรอบรูปสามมิติ 5 คน ใช้ภาพต้นฉบับที่ผู้ใช้ส่งให้และอนุมัติเผยแพร่
- ชื่อบนกรอบและคำบรรยาย: นิกกล้า, เมเจอร์, ฟิล์ม, มองคอย, ไมเคิล
- แสดง “สร้างโดย” เมื่อกล้องเลื่อนถึงบอร์ด เพิ่มป้ายชื่อ ขอบกรอบซ้อนชั้น ไฟส่องรูป และรายละเอียดโต๊ะคอม/ห้อง
- รูปย่อ WebP รวมประมาณ 152 KB รักษาสัดส่วนภาพ ไม่เปลี่ยนใบหน้าหรือสร้างบุคคลใหม่
- โหลดฟอนต์ไทยก่อนวาดชื่อซ้ำ ป้องกันฟอนต์สำรองค้างบนภาพสามมิติ และเก็บกวาดทรัพยากรเมื่อปิดการเคลื่อนไหว
- ไม่เปลี่ยน source ห้องแชท ระบบตอบคำถาม ฐานข้อมูล หรือค่าการเชื่อมต่อ AI

ตรวจในเครื่อง: unit 131 ผ่าน, retrieval 24 ผ่าน, browser 61 ผ่าน, TypeScript และ build ผ่าน หลังเก็บระยะป้ายชื่อรันทดสอบ Landing 15 รายการผ่านซ้ำ ตรวจภาพ desktop/mobile ด้วยเบราว์เซอร์แล้ว

การเผยแพร่ต้องตรวจ CI ของ commit และ revision ของ container จริง สถานะในเอกสารนี้ไม่ใช่หลักฐานว่า runtime อัปเดตแล้ว ย้อนกลับได้ด้วย image/config ของ commit ก่อนหน้า โดยคง volume เดิม

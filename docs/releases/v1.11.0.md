# C Companion 1.11.0 — ห้องแชทที่อ่านง่ายขึ้น

ปรับเฉพาะห้องแชท โดยคงหน้า Welcome/Landing เดิมและระบบตอบคำถามเดิม

- หน้าเริ่มสนทนาใช้มาสคอตขนาดเล็ก คำชวนถาม และตัวอย่าง 3 คำถาม ตัดการ์ดหนังสือและภาพโค้ดที่แย่งพื้นที่อ่าน
- แถบซ้ายเน้นเริ่มสนทนา ค้นหา และประวัติ เลือกบทเรียนและเปิดหนังสือจากแถบบน ลดปุ่มซ้ำ
- รวมโหมดถามคำถาม ติวทีละขั้น และฝึกทำโจทย์ไว้เหนือช่องพิมพ์ในกรอบเดียวกัน พร้อมสถานะโฟกัสและปุ่มส่ง/หยุด
- แหล่งอ้างอิงไม่เปิดอัตโนมัติ ผู้เรียนกดเลขหน้าหรือปุ่มอ้างอิงเมื่ออยากตรวจหนังสือได้
- บนมือถือ แผงอ้างอิงปิดการโต้ตอบพื้นหลังชั่วคราว รองรับแป้นพิมพ์ และคืนโฟกัสไปยังปุ่มที่เปิด รวมถึงกรณีเปิดหนังสือซ้อน
- ลดองค์ประกอบตกแต่งซ้ำ ใช้พื้นเขียวอ่อน ตัวอักษรอ่านง่าย และการเคลื่อนไหวสั้น รองรับ reduced motion และโหมดมืด
- คำแนะนำเปลี่ยนภาษาอยู่ในเมนูการใช้งานและคู่มือ

## การตรวจสอบ

Unit tests 131 รายการ, retrieval 24 กรณี, TypeScript, production build และ browser tests (รวม regression ใหม่สำหรับแผงอ้างอิงกับจอเล็ก) ผ่านก่อนปล่อยรุ่น ตรวจภาพจริงขนาด 320/390/1440 พิกเซลและโหมดมืดด้วย

Browser tests ใช้บริการคำตอบจำลองเพื่อทดสอบพฤติกรรมระบบ ไม่ใช่การวัดความถูกต้องของคำตอบ AI จริง รุ่นนี้ไม่ได้เปลี่ยนโมเดลหรืออ้างความแม่นยำเพิ่มขึ้น คู่มือ PDF รุ่น 1.9.0 ยังใช้อธิบายการติดตั้งเดิมได้ แต่ภาพหน้าจออาจต่างจากรุ่นนี้

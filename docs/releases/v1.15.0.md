# C Companion 1.15.0 — Mongkoi chat portrait and midnight theme

นำมองคอยจาก Landing มาเป็นภาพโปรไฟล์ในห้องแชท และปรับโหมดมืดให้เป็นดำอมคราม–แดง–งาช้าง

- เจนภาพโปรไฟล์โดยอ้างอิงโมเดลยีราฟเดิม เสื้อแดงพร้อมชื่อ “มองคอย” และ MONGKOI
- ใช้ภาพ WebP สองขนาดในแบรนด์ หน้าเริ่มสนทนา ข้างคำตอบ และขณะรอคำตอบ รวมประมาณ 32 KB
- ห้องแชทไม่โหลดโมเดล 3D หรือชุดแอนิเมชันของ Landing
- ปรับสีพื้น ปุ่มส่ง โหมดที่เลือก ประวัติ กล่องข้อความ อ้างอิง โค้ด และหน้าต่างต่าง ๆ เฉพาะโหมดมืด
- โหมดสว่างคงชุดสีและการจัดวางเดิม เปลี่ยนเฉพาะรูปมาสคอต
- คงการเลือกธีมตามระบบและการจดจำตัวเลือกของผู้ใช้
- อัปเลขรุ่นห้องแชทและแพ็กเกจเป็น 1.15.0

ตรวจ TypeScript, build, unit 131, retrieval 24 และ browser 61 กรณี รวมการสลับธีมโดยคงข้อความร่าง สีโหมดสว่างหลังสลับกลับ ภาพโหลดจากเว็บเดียวกัน มือถือ และการใช้งานห้องแชท การทดสอบตอบคำถามใช้บริการจำลอง ไม่ใช่ผลประเมินความแม่นยำ AI ใหม่

ไม่มีการแก้ Landing หรือระบบตอบคำถามในรุ่นนี้

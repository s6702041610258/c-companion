# Landing Page — C Companion

## แนวคิด

หน้าสำหรับผู้เริ่มเรียนภาษา C ให้เข้าใจว่าถามอะไรได้ เรียนอย่างไร และเริ่มใช้อย่างไร ผู้ใช้เลือกแนว cinematic 3D / dark luxury / glassmorphism และระบุ Next.js, Three.js, GSAP ScrollTrigger, Lenis จึงใช้แนวนี้เฉพาะหน้าแนะนำที่ `/welcome/` โดยห้องแชทเดิมอยู่ `/`

ภาพหลักเป็นมังกรเขียวถือหนังสือที่สร้างจาก geometry โดยเฉพาะ วงแหวน C เชื่อมเอกลักษณ์ของภาษาและผลิตภัณฑ์ ไม่ใช้ภาพหรือชิ้นงานของเว็บไซต์อ้างอิง การเลื่อนหน้าเปลี่ยนมุมกล้องและซูม ตามด้วยแกลเลอรีโหมดแนวนอนบนเดสก์ท็อป ตัวอย่างโหมดแบบโต้ตอบ หนังสือ/12บท และสองทางเลือกในการเริ่มใช้

## สีและลำดับภาพ

- Ink `#070d12`: พื้นฉาก
- Surface `#0f191f`: พื้นที่อ่าน/แสดงตัวอย่าง
- Paper `#ecf1e9`: ข้อความหลัก
- Jade `#b3e6c4`: มังกรและการเริ่มเรียน
- Blue `#a2bded`: ติวทีละขั้น
- Gold `#e1c399`: ฝึกทำโจทย์

หัวเรื่องอังกฤษขนาดใหญ่ใช้Arial น้ำหนัก500 เนื้อหาไทยใช้Noto Sans Thai400–700 การจัดวางเริ่มจากเนื้อหาซ้าย/ประติมากรรมขวา แล้วเปลี่ยนเป็นฉากโหมดเต็มพื้นที่ ก่อนกลับมาอ่านสองคอลัมน์ จุดเด่นอยู่ที่มังกรและการเลื่อน ไม่ใช้ไอคอนประกายตกแต่ง

## เทคโนโลยีและขอบเขต

Next.js static exportเป็นworkspaceแยก สร้างHTMLก่อนรันและรวมในimageเดิม ไม่มีNext serverเพิ่ม Three.js/GSAP/Lenisโหลดเฉพาะหน้าแนะนำและเมื่อเปิดmotion ห้องแชทไม่โหลดไลบรารี3D

รองรับprefers-reduced-motionและปุ่มปิดmotion: ไม่มีsmoothscroll/pin/กล้องเคลื่อน ใช้ภาพSVGและการ์ดแนวตั้ง เนื้อหาและลิงก์ทั้งหมดอ่านได้แม้ปิดJavaScript มือถือไม่มีhorizontal pin และใช้pixel ratioไม่เกิน1 เดสก์ท็อปไม่เกิน1.5 Three.jsเรนเดอร์ตามเหตุการณ์ ไม่ใช้loopตลอดเวลา หยุดเมื่อพ้นจอหรือแท็บซ่อน และdisposegeometry/material/listenerเมื่อปิดmotion WebGLไม่พร้อมใช้ภาพSVGแทน

CSPอนุญาตinlinehydrationเฉพาะhashจากHTMLที่buildแล้ว ไม่เพิ่มunsafe-inlineให้script-src ไม่เปิดeval APIและห้องแชทยังใช้policyเดิม

ตัวอย่างแชทระบุว่าเตรียมไว้ ไม่เรียกAIอัตโนมัติ ไม่สร้างผลวิจัยหรือรีวิวลูกค้าขึ้นเอง การติดตั้งเองไม่ได้รับประกันออฟไลน์หรือไม่มีค่าใช้บริการAI

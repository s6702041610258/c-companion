# C Companion 1.9.1 — เปิด Welcome ก่อนเริ่มใช้งาน

เปิดที่อยู่หลัก `/` จะเข้าสู่ `/welcome/` ทุกครั้ง ทั้งผู้ใช้ใหม่และผู้ใช้เดิม จากนั้นกดเริ่มเรียนภาษา C หรือเปิดห้องแชทเพื่อไป `/chat/` ปรับปุ่มเข้าห้องแชททุกจุดให้ใช้เส้นทางใหม่ โลโก้ในห้องแชทกลับหน้า Welcome ส่วนการรีเฟรชห้องแชทยังคงอยู่หน้าที่กำลังใช้งาน

ปรับ `/index.html` และทางเข้ารุ่นเก่า `/c-tutor/` ให้เข้าสู่ Welcome ด้วย ใช้ redirect แบบไม่เก็บแคช ไม่เปลี่ยน cookie ผู้ใช้ ประวัติสนทนา API หรือนโยบายคำตอบ

คู่มือ PDF รุ่น1.9.0ยังใช้กับขั้นตอนติดตั้งและใช้งานได้ โดยทางเข้าเว็บหลักเปลี่ยนตามรายการนี้

ชื่อแท็บห้องแชทใช้ “C Companion — เปลี่ยนคำถาม ให้เป็นความเข้าใจ” พร้อมไอคอน C ไฟล์เดียวกับ Welcome

## การตรวจ

ตรวจเส้นทางหน้าแรก การเข้าห้องแชทจากปุ่ม การรีเฟรช การกลับหน้าหลัก และการกลับมาใช้ซ้ำ พร้อมชุดตรวจ unit, retrieval, TypeScript, build และ browser regression ของโปรเจกต์

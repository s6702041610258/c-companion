# C Companion 1.9.0 — หน้าแนะนำระบบแบบ3D

เปิดหน้าใหม่ที่ `/welcome/` และเข้าห้องแชทเดิมได้ที่ `/`

- หน้าแนะนำโทนมืด ใช้มังกรเขียว3Dถือหนังสือที่สร้างขึ้นสำหรับC Companion พร้อมวงแหวนC แสงและวัสดุสะท้อน
- กล้องซูมและเปลี่ยนมุมตามการเลื่อน มังกรตอบสนองตำแหน่งเมาส์ พร้อมแกลเลอรีแนวนอนอธิบายถาม/ติว/ฝึกบนเดสก์ท็อป
- ตัวอย่างบทสนทนากดสลับสามโหมดและใช้คีย์บอร์ดได้ ระบุชัดว่าเตรียมไว้ ไม่เรียกAIอัตโนมัติ
- อธิบายที่มาของคำตอบ เนื้อหา12บท ทางเลือกใช้เว็บ/ติดตั้งเอง คู่มือและFAQ
- รองรับมือถือ ลดการเคลื่อนไหว ปุ่มปิดmotion ภาพสำรองเมื่อWebGLใช้ไม่ได้ และเนื้อหาหลักอ่านได้เมื่อปิดJavaScript
- ใช้Next.js static export, Three.js, GSAP ScrollTrigger และLenis หน้าแนะนำโหลดแยกจากห้องแชท ไม่มีNext serverเพิ่ม
- 3Dเรนเดอร์ตามเหตุการณ์ จำกัดpixel ratio หยุดเมื่อพ้นจอ/ซ่อนแท็บ ปิดmotionเริ่มต้นเมื่อเครื่องแจ้งSave-Dataหรือหน่วยความจำไม่เกิน2GB (ผู้ใช้เปิดเองได้)
- CSPอนุญาตinlinehydrationเฉพาะhashของไฟล์ที่buildแล้ว ไม่เพิ่มunsafe-inline/unsafe-evalให้script-src
- เพิ่มลิงก์หน้าแนะนำในเมนูการใช้งานและคู่มือ อัปเดตคู่มือ12หน้าและ4หน้าเป็นรุ่น1.9.0

## การตรวจ

ทดสอบหน่วย131กรณี ชุดค้นคืน24กรณี และเบราว์เซอร์49กรณี รวมCSP ตัวอย่างแชท คีย์บอร์ด ปิดmotion WebGLfallback และปิดJavaScript ตรวจภาพจริง320/390/1440พิกเซลในโหมดปกติและลดการเคลื่อนไหว ตรวจTypeScript/buildและdependency audit

ผลทดสอบระบบไม่ใช่คะแนนความถูกต้องของAI รุ่นนี้ไม่เปลี่ยนนโยบายการตอบ ข้อมูลวิจัย หรือschemaฐานข้อมูล

## การติดตั้งและย้อนรุ่น

`npm ci` ติดตั้งทั้งworkspace และ `npm run build` สร้างห้องแชทกับหน้าแนะนำรวมกัน Dockerยังเสิร์ฟผ่านNodeHTTPเดิม หน้าแนะนำเป็นstaticfiles ใช้image1.8.0กับvolumeเดิมเพื่อย้อนรุ่นได้ (จะไม่มีหน้าใหม่) ควรสำรองและทดสอบกู้คืนสำเนาก่อนอัปเดต
